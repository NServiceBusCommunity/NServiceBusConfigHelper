# Adding features to an NServiceBus endpoint

Generated by the [NServiceBus wizard](https://nservicebuscommunity.github.io/NServiceBusConfigHelper/add?step=output&transport=RabbitMQ&persistence=PostgreSql&features=AttachmentsSql). The files next to this guide are changes to merge into an existing endpoint, not a solution. Adding: SQL attachments.

Package versions: the newest stable releases as of 2026-10-01; nuget.org was not checked when this was generated.

## Steps

1. Merge the `PackageVersion` items from `Directory.Packages.props.fragment.xml` into `Directory.Packages.props`. Without central package management, put each version on the matching `PackageReference` in the next step instead.
2. Merge the `PackageReference` items from `Endpoint.csproj.fragment.xml` into the endpoint's project file.
3. Merge `Program.fragment.cs` into the code that configures the endpoint. It is grouped by where each statement goes, and refers to the endpoint's own `builder`, `endpointConfiguration` and `transport` variables.
4. Add the connection strings in `appsettings.fragment.json` to the endpoint's settings, or point the statements at connection strings it already has.
5. For a local run, `docker-compose.fragment.yml` has a container for SQL Server. Its password is in the clear, which is fine for a container on a developer's machine and nowhere else.
6. SQL Server starts with no database. Create it once the container is up: `docker compose exec sqlserver /opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P NServiceBus-Dev-1 -C -Q "CREATE DATABASE [SampleEndpoint]"`.
7. Copy `Messages/StoreDocument.cs`, `Handlers/StoreDocumentHandler.cs`, `Attachments/DocumentSender.cs` into the endpoint project, and change the namespace `SampleEndpoint` to the project's own.
8. Build and run the endpoint.

## What each feature adds

### SQL attachments

The claim check pattern on SQL Server: large content travels beside the message in a table, and is streamed when a handler asks for it. An NServiceBus Community extension. [Documentation](https://github.com/NServiceBusCommunity/NServiceBus.Community.Attachments/blob/main/docs/sql.md).

```cs
endpointConfiguration.EnableAttachments(
    () => new SqlConnection(sqlServerConnectionString),
    TimeToKeep.Default);
```

Files: `Messages/StoreDocument.cs`, `Handlers/StoreDocumentHandler.cs`, `Attachments/DocumentSender.cs`.

 * Reads the `SqlServer` connection string. A SQL Server database the endpoint can create tables in.
 * Attachments are kept in a `MessageAttachments` table, which installers create. `TimeToKeep.Default` keeps an attachment for ten days, or for twice the message's time to be received when it has one.

## Worth knowing

 * **SQL attachments**: SQL attachments is an NServiceBus Community extension: MIT licensed, and developers who use it are expected to [become patrons](https://github.com/NServiceBusCommunity/Home#community-backed).

==== Messages/StoreDocument.cs

namespace SampleEndpoint.Messages;

/// <summary>The document's content travels as an attachment named "content", not in the message body.</summary>
public class StoreDocument :
    ICommand
{
    public string Name { get; set; } = "";
}

==== Handlers/StoreDocumentHandler.cs

using SampleEndpoint.Messages;

namespace SampleEndpoint;

public class StoreDocumentHandler(ILogger<StoreDocumentHandler> logger) :
    IHandleMessages<StoreDocument>
{
    public async Task Handle(StoreDocument message, IMessageHandlerContext context)
    {
        // Read on demand: nothing is loaded until it is asked for, and a large attachment can
        // be copied to a stream instead with CopyTo.
        var attachments = context.Attachments();
        var content = await attachments.GetString("content", cancel: context.CancellationToken);
        logger.LogInformation("Document {Name} has {Length} characters", message.Name, content.Value.Length);
    }
}

==== Attachments/DocumentSender.cs

using SampleEndpoint.Messages;

namespace SampleEndpoint;

/// <summary>Sends a <see cref="StoreDocument"/> with its content attached.</summary>
public static class DocumentSender
{
    public static Task Send(IMessageSession session, string name, string content)
    {
        var options = new SendOptions();
        options.RouteToThisEndpoint();
        var attachments = options.Attachments();
        attachments.AddString("content", content);
        return session.Send(
            new StoreDocument
            {
                Name = name
            },
            options);
    }
}
