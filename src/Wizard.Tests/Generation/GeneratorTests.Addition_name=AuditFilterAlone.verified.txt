# Adding features to an NServiceBus endpoint

Generated by the [NServiceBus wizard](https://nservicebuscommunity.github.io/NServiceBusConfigHelper/add?step=output&transport=SqlServer&persistence=SqlServer&features=AuditFilter,Heartbeats). The files next to this guide are changes to merge into an existing endpoint, not a solution. Adding: Audit filter, Heartbeats.

Package versions: the newest stable releases as of 2026-10-01; nuget.org was not checked when this was generated.

## Steps

1. Merge the `PackageVersion` items from `Directory.Packages.props.fragment.xml` into `Directory.Packages.props`. Without central package management, put each version on the matching `PackageReference` in the next step instead.
2. Merge the `PackageReference` items from `Endpoint.csproj.fragment.xml` into the endpoint's project file.
3. Merge `Program.fragment.cs` into the code that configures the endpoint. It is grouped by where each statement goes, and refers to the endpoint's own `builder`, `endpointConfiguration` and `transport` variables.
4. Build and run the endpoint.

## What each feature adds

### Audit filter

Chooses which message types go to the audit queue, with an attribute on the message or a default for the rest. An NServiceBus Community extension. [Documentation](https://github.com/NServiceBusCommunity/NServiceBus.Community.AuditFilter).

```cs
endpointConfiguration.FilterAuditQueue(FilterResult.IncludeInAudit);
```

 * Messages with no audit attribute: Audit them. Everything is audited except the types marked [ExcludeFromAudit].
 * Mark a message class with `[IncludeInAudit]` or `[ExcludeFromAudit]` to decide for that type, whatever the default is.

### Heartbeats

Tells ServiceControl at a regular interval that the endpoint is alive, so ServicePulse can show when it stops. [Documentation](https://docs.particular.net/monitoring/heartbeats/).

```cs
endpointConfiguration.SendHeartbeatTo("Particular.ServiceControl");
```

## Worth knowing

 * **Audit filter, Auditing**: Audit filter configures Auditing. If the endpoint does not have it yet, select it here as well.
 * **Heartbeats**: Heartbeats sends to ServiceControl's queues. Until [ServiceControl](https://docs.particular.net/servicecontrol/) has been installed and has created them, those messages have nowhere to go.
 * **Audit filter**: Audit filter is an NServiceBus Community extension: MIT licensed, and developers who use it are expected to [become patrons](https://github.com/NServiceBusCommunity/Home#community-backed).
 * **SQL Server transport, SQL Server persistence**: The transport and the persistence are in one database, on one connection string. SQL persistence then uses the connection and transaction the transport receives the message on, so the data and the messages a handler sends commit together without the outbox; see [combining SQL Server persistence and transport](https://docs.particular.net/persistence/sql/sqlserver-combining-persistence-wth-transport).
