# Adding features to an NServiceBus endpoint

Generated by the [NServiceBus wizard](https://nservicebuscommunity.github.io/NServiceBusConfigHelper/add?step=output&transport=RabbitMQ&persistence=MongoDb&features=Serilog). The files next to this guide are changes to merge into an existing endpoint, not a solution. Adding: Serilog.

Package versions: the newest stable releases as of 2026-10-01; nuget.org was not checked when this was generated.

## Steps

1. Merge the `PackageVersion` items from `Directory.Packages.props.fragment.xml` into `Directory.Packages.props`. Without central package management, put each version on the matching `PackageReference` in the next step instead.
2. Merge the `PackageReference` items from `Endpoint.csproj.fragment.xml` into the endpoint's project file.
3. Merge `Program.fragment.cs` into the code that configures the endpoint. It is grouped by where each statement goes, and refers to the endpoint's own `builder`, `endpointConfiguration` and `transport` variables.
4. Build and run the endpoint.

## What each feature adds

### Serilog

Logs through Serilog, with NServiceBus exception details as structured properties, and a log event for each message handled and sent. An NServiceBus Community extension. [Documentation](https://github.com/NServiceBusCommunity/NServiceBus.Community.Serilog).

```cs
var loggerConfiguration = new LoggerConfiguration();
loggerConfiguration.Enrich.WithNsbExceptionDetails();
loggerConfiguration.WriteTo.Console();
Log.Logger = loggerConfiguration.CreateLogger();

// Serilog takes the place of the host's own providers, so each event is written once.
builder.Logging.ClearProviders();
builder.Logging.AddSerilog();

var serilogTracing = endpointConfiguration.EnableSerilogTracing(Log.Logger);
serilogTracing.EnableMessageTracing();
```

 * Message tracing writes an event for every message received and sent, enriched with the message id, type, correlation id and conversation id. Inside a handler, `context.Logger()` is a logger that already carries them.

## Worth knowing

 * **Serilog**: Serilog is an NServiceBus Community extension: MIT licensed, and developers who use it are expected to [become patrons](https://github.com/NServiceBusCommunity/Home#community-backed).
