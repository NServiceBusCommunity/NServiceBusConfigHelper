Adding features to an NServiceBus endpoint

Generated by the NServiceBus wizard. The files next to this guide are changes to merge into an existing endpoint, not a solution. Adding: Sagas, Serilog.

Package versions: the newest stable release of each on nuget.org when this was generated.

Steps

  1. Merge the PackageVersion items from Directory.Packages.props.fragment.xml into Directory.Packages.props. Without central package management, put each version on the matching PackageReference in the next step instead.
  2. Merge the PackageReference items from Endpoint.csproj.fragment.xml into the endpoint's project file.
  3. Merge Program.fragment.cs into the code that configures the endpoint. It is grouped by where each statement goes, and refers to the endpoint's own builder, endpointConfiguration and transport variables.
  4. Copy Sagas/OrderSaga.cs, Sagas/OrderSagaData.cs, Sagas/CancellationWindowElapsed.cs into the endpoint project, and change the namespace SampleEndpoint to the project's own.
  5. Those files refer to sample messages and a sample handler, which are in Samples/. Point the copied code at the endpoint's own messages instead, or copy the samples too.
  6. Build and run the endpoint.

What each feature adds

Sagas

A long-running process with its own state: a sample saga that is started by an event and completes on a timeout. Documentation.

Files: Sagas/OrderSaga.cs, Sagas/OrderSagaData.cs, Sagas/CancellationWindowElapsed.cs.

  • A saga's state is stored by the persistence. Messages for one saga instance are handled one at a time: a concurrent update fails and is retried.
  • A timeout is a message sent to the saga itself with a delay, so it survives a restart.

Serilog

Logs through Serilog, with NServiceBus exception details as structured properties, and a log event for each message handled and sent. An NServiceBus Community extension. Documentation.

var loggerConfiguration = new LoggerConfiguration();
loggerConfiguration.Enrich.WithNsbExceptionDetails();
loggerConfiguration.WriteTo.Console();
Log.Logger = loggerConfiguration.CreateLogger();

// Serilog takes the place of the host's own providers, so each event is written once.
builder.Logging.ClearProviders();
builder.Logging.AddSerilog();

var serilogTracing = endpointConfiguration.EnableSerilogTracing(Log.Logger);
serilogTracing.EnableMessageTracing();
  • Message tracing writes an event for every message received and sent, enriched with the message id, type, correlation id and conversation id. Inside a handler, context.Logger() is a logger that already carries them.

Worth knowing

  • Serilog: Serilog is an NServiceBus Community extension: MIT licensed, and developers who use it are expected to become patrons.
Full documentation is at docs.particular.net. The extensions are from NServiceBus Community. Wizard source: NServiceBusCommunity/NServiceBusConfigHelper.
