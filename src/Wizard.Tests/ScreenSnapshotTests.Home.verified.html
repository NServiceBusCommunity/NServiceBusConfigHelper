NServiceBus Wizard

Configure an NServiceBus endpoint: a working solution, a guide, and instructions for an AI assistant.

Pick a starting point. Each flow asks a few questions, then produces a guide, a download and markdown for an AI assistant.

New endpoint

Start from scratch: hosting, transport, persistence, serializer and tests, plus any features. The result is a solution that builds and runs.

Add features to an existing endpoint

Pick features to add: sagas, the outbox, monitoring, or an NServiceBus Community extension. The result is only what has to be merged in.

Every page's url holds the choices made so far, so any point can be bookmarked or shared.

This browser remembers the transport and the persistence of the endpoint features were last added to, to fill them in next time.
